# model-salt

The short name for [@modelsalt/model-salt](https://www.npmjs.com/package/@modelsalt/model-salt). `npx -y model-salt <args>` runs the same thing as `npx -y @modelsalt/model-salt <args>`.

Model Salt is an MCP server that gives your model randomness from outside it, so one prompt gives different answers that still do what you asked.

```sh
npx -y model-salt setup claude      # or codex, gemini, kimi
npx -y model-salt uninstall claude  # takes out everything setup added
```

Docs and examples: [modelsalt.com](https://modelsalt.com) and [github.com/modelsalt/model-salt](https://github.com/modelsalt/model-salt).
